# PAGE VERSION REGISTRY — Breus Media

Единый реестр и версионирование страниц проекта `breus.media`.
Каждая доработка фиксируется под постоянным кодом версии с живой ссылкой Vercel Preview и набором параметров, чтобы можно было в любой момент вернуться к любому варианту без потери настроек.

## 🚁 Маршрут: `/drone-service` (Аэросъёмка дроном для бизнеса)

### [DRONE-V1.0] — Базовый исходник (Legacy 1.0)
- **Живая ссылка Vercel Preview**: [https://breus-media-v2-nis3duab4-tony-breus-projects.vercel.app/drone-service](https://breus-media-v2-nis3duab4-tony-breus-projects.vercel.app/drone-service)
- **Дата фиксации**: 2026-09-05 (Утро)
- **Статус**: `Архив (Исходная версия)`
- **Архитектурный профиль**:
  * **Hero**: Скорость смены слайдов 5000 мс (высокая частота). Заголовок H1 скрыт через класс `sr-only`. На мобильном экране развернут 4-абзацный текст «печатной машинки» с прыгающей стрелкой.
  * **Услуги (18 направлений)**: Двойное дублирование на мобильных — сначала сетка из 18 кнопок списком (`DroneServicesMobileList`), а сразу под ней 18 крупных карточек (14 экранов скролла).
  * **Изображения карточек**: Стоковые ссылки Unsplash с битыми параметрами CDN на части карточек.
  * **Цены карточек**: Смешанная строка без чёткого выделения стартового тарифа в лари.
  * **Форма заявки**: Поле «Ваши соцсети или сайт» (высокое трение для мобильных). Ссылка WhatsApp — неприметный серый текст.
  * **Тарифы**: 4 карточки вертикальным стеком. Без явной Answer Capsule под H2.
  * **Плавающий WhatsApp**: Локальные компоненты баров возвращали `null;`.
- **Оценка 30-факторного аудита**: **14 / 30** (Критика по первому экрану, дублированию 18 карточек и скрытому H1).
